02 / SCOPE

What counts as crypto?

How findings are matched

Each matched row shows the exact clue. Specific clues include weak or deprecated crypto, legacy SSL 2/3 or TLS 1.0/1.1, examples of weak algorithms such as MD5, SHA-1, DES, and RC4, selected crypto-related CWE codes (295, 326, 327, 330), and known mining tools or pool terms. General encryption, certificate, or key wording is treated as context. Known crypto libraries include OpenSSL, libssl/libcrypto, BoringSSL, wolfSSL, GnuTLS, mbedTLS, cryptsetup, libgcrypt, libsodium, bcrypt, and Bouncy Castle. They are detected in package/component fields; if those fields are absent, CryptoLens checks finding text, or the whole row when it cannot identify finding columns. A library mention alone does not prove the reported issue is a crypto vulnerability. A CVE ID by itself never triggers a match. This keyword filter is a review aid, not a severity assessment.
